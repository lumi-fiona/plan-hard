**Does every credential in the design carry a rough real lifetime?**

Access tokens, refresh tokens, the short code the TV displays, the session cookie — anything that expires, rotates or gets revoked.

PASS if the answer attaches actual durations to them, even approximate ones, and says what the user sees when one runs out.

FAIL if lifetimes are described only in words like "short-lived", "long-lived" or "until revoked", with no numbers and no visible expiry behaviour. A plan that gives numbers for some and hand-waves the rest still fails — the point is that the perishable parts were all counted.

Answer PASS or FAIL.
