**Is there a fallback for signing in on the TV if the device flow can't be used?**

PASS if at least one alternative path is described — pairing from the already-signed-in web session, a short code the server issues itself, a phone-side approval, or similar. It needs to be concrete enough to build, not just the sentence "we could do something else".

FAIL if the plan has exactly one way for the TV to sign in and no answer for the day it stops working.

Answer PASS or FAIL.
