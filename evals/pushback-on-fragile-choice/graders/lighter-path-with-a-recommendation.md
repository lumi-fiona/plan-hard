**Is a lighter alternative named, and does the answer say which it would choose?**

PASS if it describes a concrete simpler option — a health endpoint per service, an existing uptime checker, plain HTTP checks with a login only where one is truly needed — and then states a recommendation.

FAIL if no alternative appears. Also FAIL if two options are laid side by side with no opinion, because a menu with no recommendation hands the decision back to the person who asked for advice.

Answer PASS or FAIL.
